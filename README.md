PALMERA BAY — an original open-world crime game in the spirit of GTA 6, built for make.fun's "Make GTA 6" bounty. Drive and steal cars across Palmera Bay, take on six story missions, outrun the PBPD police across wanted levels, with traffic and pedestrians, combat, a HUD with minimap, and a save system. No libraries, no network requests — plain static files, keyboard and mouse.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
